Core Journey Through the System

PRD behaviors mapped to components

Flow

User does X → API/app handles → state updates → UI shows result

  • First open → /setup/status → first-run screen
  • Interview + bands → Gemini Pro suggests bands, fallback to manual if fails → saved to SQLite
  • Today → Load goal/bands/rank/logs, render Kael on leftmost (head-to-waist, no crop) → S/R +1, Floor locked
  • Tonight → Brain dump → Gemini generates top 3 quests → saved
  • Log → Update logs, track consecutive, apply rank penalty/up
  • Week check-in → Analyze after ≥3 nights, propose changes, Honest Week fires live
  • Refusal → Block Floor/lower-band changes, allow partial raise
03

Ranks, Coach & UI

Key rules from requirements

Ranks

Penalty: -1 on 2 consecutive Nothing or unlogged days count as Nothing (never below Spark). Up: +2 on 3 consecutive ≥Realistic, +1 on 3 consecutive ≥Floor. Ranks: Spark → Kindle → Flame → Blaze → Inferno.

Kael (Coach)

Image: devpost/assets/Gemini_Generated_Image_owkwf4owkwf4owkw.jpg. Head-to-waist, folded-arm knight with sword, no cropping, scale as needed, leftmost part of page. Visible on Today, Tonight, Week.

Look & Feel

Deep navy blue primary. Windows/icons in deep navy/purple/red only for negative alerts. 3D feel (beveled, shadows). No flashy motion.

Storage & Deploy

Python FastAPI + SQLite (ephemeral). Deploy to Google Cloud Run. React Native Expo app talks to API via API_BASE_URL.
