# Ember

**An evening companion that keeps a goal alive by carving it into three bands: Stretch, Realistic and Floor.**

Most goal trackers trust one target, so they swing with your mood and get abandoned on a hard day. Ember treats every goal as a **band**, not a number. The **Floor is the smallest version that still counts, it is never zero**, and it only moves on evidence from your logs, never on how you feel tonight. A small win is a real win.

---

## How it works

Ember is guided by **Kael**, a calm shadow-knight coach, in a dark-fantasy "system" interface.

1. **Name a goal and why it matters.** Kael asks 8 to 10 questions tailored to *that* goal (public speaking gets different questions from a gym goal).
2. **See your bands.** The AI sets Stretch, Realistic and Floor in the goal's own unit (minutes of practice, sessions, words), each with a concrete description and a reason drawn from your answers.
3. **Evening shutdown.** Type a messy brain dump and Kael turns it into **tomorrow's top three**, each with a first step small enough to start tired.
4. **One-tap nightly log.** Stretch, Realistic, Floor or Nothing. Rank moves along **Spark, Kindle, Flame, Blaze, Inferno** as nights stack up, and two Nothing days in a row cost a rank.
5. **Weekly evaluation.** After three logged nights, Kael asks three questions about your week. Only after the third answer does the AI propose a **single, one-step change**, which you accept.
6. **Consult Kael.** Talk to the coach at any time. Replies are generated by the AI and stay in the same window.

### Rules the product enforces in code

The AI suggests, the code decides. These hold no matter what a model returns:

- The Floor is never zero and the user cannot lower it. Only Ember's weekly proposal can move it, by one step, after repeated misses.
- A proposal changes at most one band, by one step, and the ladder Floor < Realistic < Stretch must still hold.
- Tonight always yields exactly three quests, and one of them is Floor-sized.
- If the AI is unavailable, the app stays calm and usable. It shows a gentle message and falls back to simple behaviour instead of breaking.

## Choose your AI: no billing needed

Ember works with **any one** of three options, so judges can pick whichever is convenient:

- **Groq** with a free key (no billing)
- **Vertex AI (Gemini)** on Google Cloud
- **Offline mode**, with no key at all

No specific model or cloud is required. You select one with `AI_PROVIDER` in `backend/.env`. The exact variables, supported models and troubleshooting are in [`backend/README.md`](backend/README.md).

## Quick start

You need **Python 3.11+** and **Node.js 20+**. Start the backend first, then the frontend.

**1. Backend** (FastAPI + SQLite, port 8082). Create a virtual environment, install the requirements, copy `.env.example` to `.env`, choose your AI provider and run the server:

```bash
cd backend
python -m venv .venv
python -m pip install -r requirements.txt   # run inside the activated virtual environment
uvicorn app.main:app --host 127.0.0.1 --port 8082
```

Activation, provider setup, the health check and troubleshooting: see [`backend/README.md`](backend/README.md).

**2. Frontend** (React + Vite, port 5173):

```bash
cd frontend
npm install
npm run dev
```

Pointing it at the backend, the screens and troubleshooting: see [`frontend/README.md`](frontend/README.md).

**3. Open** http://localhost:5173, create a goal and walk through the loop. To see the **Week** tab straight away, seed past nights with `python backend/scripts/seed_demo.py`.

Deploying your own copy on Google Cloud Run is covered in [`DEPLOY.md`](DEPLOY.md).

## Status and known limits

This is a proof of concept.

- One goal at a time, by design (multi-goal is out of scope for now).
- **Achievements** and **Reminder** are static previews. Reminders are an in-app preview, not real push notifications.
- Data is stored in SQLite. On Cloud Run it lives in temporary storage and resets when the instance restarts.
- A shared free Groq key has rate limits. When one is hit, Kael answers with a calm "silent for a moment" message instead of failing.
